## Root cause outside my row: Lever requirements never stored

`supabase/functions/_shared/ats/lever.ts:150` stores `descriptionRaw` from `descriptionPlain`/`description` only.
Lever's postings API carries the requirement bullets in `lists[]` (`{text, content}` HTML) and closing text in
`additional`/`additionalPlain`. Keyloop, Netomi and Egen keep "N+ years" there, so every Lever JD reaches the
screener (experience, work-auth, tech gate) without its requirements section. **Suggested parcel (not mine to write):**
concatenate `description + lists[].text/content + additional` in `lever.ts`, then replay. That likely closes more
leaks than this regex change. Owner: whoever holds `_shared/ats/`.
