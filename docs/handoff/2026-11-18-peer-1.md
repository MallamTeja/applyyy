No lane shows `scored`, so a matched-but-untailored backlog is invisible on this page. Adding `scored` to the lane is a product call for Teja.

The grid then renders `null`, so the loaded rows are hidden behind a banner implying they are shown. This is a small web bug in my write set, and it was not triggered here. Fix it only if the orch assigns it.
