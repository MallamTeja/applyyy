## Known limits

- A whitespace-only description passes the queue filter but is blank to screen-batch. Such a row is fetched and held again on every run and can occupy a queue slot. The ponytail notes in `index.ts` and `queue.ts` say so.
- The normalizer moves `discovered → deduped` without needing text, so the held path is `discovered → deduped → (waits) → judged when text arrives`.
